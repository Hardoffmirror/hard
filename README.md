# PoE Currency Exchange Helper

Приложение-оверлей для Path of Exile, которое помогает отслеживать цены валют, анализировать выгодность обмена и принимать обоснованные торговые решения.

## Возможности

- **Прозрачное оверлей-окно** - отображается поверх игры, не мешая игровому процессу
- **Отслеживание цен в реальном времени** - автоматическое обновление курсов валют через poe.ninja API
- **Калькулятор выгодности** - расчет прибыльности обменов с учетом спредов
- **История цен** - хранение и визуализация исторических данных
- **Графики и статистика** - визуализация трендов, волатильности и прибыльности
- **Поиск арбитража** - автоматический поиск выгодных цепочек обмена
- **База данных** - локальное хранение всех данных для анализа

## Возможности интерфейса

### Вкладка "Exchange Rates"
- Таблица с текущими курсами всех валют
- Изменения цен за 24 часа
- Процент прибыльности
- Рекомендации по покупке/продаже

### Вкладка "Price History"
- Графики изменения цен
- Сравнение нескольких валют
- Анализ трендов

### Вкладка "Statistics"
- Общая статистика по сделкам
- Самая прибыльная валюта
- Лучшее время для торговли
- Средняя прибыль

## API и источники данных

### poe.ninja API
Основной источник данных о ценах валют:
- Endpoint: `https://poe.ninja/api/data/currencyoverview`
- Обновление: каждые 60 секунд (по умолчанию)
- Данные: цены, тренды, спреды

### Официальный Trade API
Дополнительный источник для прямых сделок:
- Endpoint: `https://www.pathofexile.com/api/trade/exchange`
- Использование: поиск конкретных предложений

## База данных

Приложение использует SQLite для хранения данных:

### Таблицы:
- `price_history` - история цен валют
- `trade_statistics` - статистика по совершенным сделкам

### Автоматическая очистка:
Старые данные (>30 дней) автоматически удаляются

## Устранение неполадок

### Проблема: Окно не отображается поверх игры

**Решение**: Убедитесь, что игра запущена в оконном или полноэкранном оконном режиме (не fullscreen exclusive).

### Проблема: Нет данных о ценах

**Решение**:
1. Проверьте подключение к интернету
2. Убедитесь, что poe.ninja доступен
3. Проверьте, что в config.py указана правильная лига

### Проблема: Приложение тормозит

**Решение**:
1. Увеличьте `UPDATE_INTERVAL` в config.py
2. Уменьшите `MAX_HISTORY_DAYS` для меньшего объема данных

## Ограничения и предостережения

- **Rate Limiting**: poe.ninja имеет ограничения на частоту запросов. Не уменьшайте UPDATE_INTERVAL ниже 30 секунд
- **Точность данных**: Данные предоставляются сторонними API и могут отличаться от реальных цен в игре
- **Использование**: Приложение предназначено только для информационных целей
